# NextGenStreamBot

Multi-Platform Stream Notification Bot mit Discord-Integration und Web-Dashboard.

## Features

- Discord-Bot mit Live-Benachrichtigungen
- Web-Dashboard zur Konfiguration
- Multi-Platform Support (Twitch, Kick, TikTok, YouTube)
- Audit-Log für alle Aktionen
- Theme-Switcher (Ocean, Coral, Gold)
- Premium-System
